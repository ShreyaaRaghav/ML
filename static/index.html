About this system

Architecture — Uncertainty-Aware Cascaded Ensemble

The system processes each network traffic record through three sequential stages, avoiding unnecessary multiclass classification for traffic that can be confidently identified as normal.

1
Binary screening LightGBM classifies each record as Normal or Suspicious. Records below the probability threshold exit here labelled Normal.
↓
2
Attack classification CatBoost assigns the most likely attack category to suspicious records. Nine attack types are covered: DoS, Exploits, Fuzzers, Generic, Reconnaissance, Backdoor, Analysis, Shellcode, Worms.
↓
3
Confidence margin M = p1 − p2. When the gap between the top two predictions is below a validation-selected threshold, the record is escalated for review rather than accepted as a confident prediction.

Dataset

UNSW-NB15 — a network intrusion dataset created at UNSW Canberra. It contains nine attack families plus normal traffic across 49 features extracted from raw network packets.
